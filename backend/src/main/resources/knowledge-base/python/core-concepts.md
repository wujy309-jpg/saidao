# Python实训知识库

## 1. Python基础

### 1.1 数据类型
- **数值**: int, float, complex
- **字符串**: str, 不可变序列
- **列表**: list, 可变序列
- **元组**: tuple, 不可变序列
- **字典**: dict, 键值对
- **集合**: set, 无序不重复

### 1.2 函数
- `def` 定义函数
- 参数: 位置参数、关键字参数、默认参数、可变参数
- 返回值: return语句
- 匿名函数: lambda

### 1.3 面向对象
- `class` 定义类
- `__init__` 构造方法
- 继承: class Child(Parent)
- 多态: 方法重写
