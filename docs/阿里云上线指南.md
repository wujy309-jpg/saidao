# 阿里云正式上线指南（赛道 · 对外版）

> 适用版本：v2.0（Spring Boot 内置前端 + MySQL 8.0，双容器部署）
> 目标：正式对外提供服务（含域名、ICP 备案、HTTPS）

## 一、部署架构

```
用户浏览器
    │  https://你的域名.com
    ▼
ECS 安全组（只放行 22/80/443）
    ▼
nginx（80→443 跳转，HTTPS 证书，反代）
    │
    ▼
Docker 容器 saidao-backend（127.0.0.1:8080）
    │        │
    │        ├─ React 前端 → /（内置 jar）
    │        ├─ API → /api/**
    │        └─ 上传文件 → 卷 backend-uploads
    ▼
Docker 容器 saidao-mysql（MySQL 8.0，卷 mysql-data）
```

- **为什么正式对外用 MySQL 而不是 H2**：H2 文件库适合开发调试；对外多用户并发、防数据损坏、备份恢复，MySQL 更可靠。项目已配好（`docker-compose.prod-mysql.yml`），一条命令即可。
- 数据都存在 Docker 卷里：`mysql-data`（数据库）、`backend-uploads`（上传文件）、`backend-logs`（日志）。

## 第 11 步：备案通过后 → 域名 + HTTPS

1. 控制台 → **云解析 DNS** → 你的域名 → 添加 A 记录：`@` → 公网 IP（另加一条 `www`）
2. 控制台 → **SSL 证书** → 免费证书 → 申请你域名的证书 → 下载 **Nginx 版**（得到 `.pem` 和 `.key`）
3. 服务器安装 nginx：

```bash
# Alibaba Cloud Linux 3
dnf install -y nginx
# Ubuntu
apt install -y nginx

mkdir -p /etc/nginx/certs
# 把 .pem / .key 上传到 /etc/nginx/certs/ 下
```

4. 写配置 `/etc/nginx/conf.d/saidao.conf`：

```nginx
server {
    listen 80;
    server_name 你的域名.com www.你的域名.com;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl;
    server_name 你的域名.com www.你的域名.com;

    ssl_certificate     /etc/nginx/certs/你的域名.pem;
    ssl_certificate_key /etc/nginx/certs/你的域名.key;

    client_max_body_size 50m;    # 和项目上传上限一致

    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # WebSocket 支持（/api/ws 长连接）
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
```

5. 生效并开机自启：

```bash
nginx -t
systemctl enable --now nginx
```

6. 浏览器访问 `https://你的域名.com` ✅
7. **收口安全组**：删除 8080 的 `0.0.0.0/0` 规则，8080 只允许本机访问（对外只剩 22/80/443）

## 附录 B：内存不足的备用构建方案

2C4G 构建没问题。若用 2C2G 构建失败：本地构建镜像 → 推送到阿里云**容器镜像服务 ACR 个人版（免费）** → 服务器拉取。步骤：

1. 本地 Mac：`docker build -t registry.cn-hangzhou.aliyuncs.com/命名空间/saidao-backend:v1 -f backend/Dockerfile .`
2. `docker login --username=阿里云账号 registry.cn-hangzhou.aliyuncs.com` 后 `docker push ...`
3. 服务器把 `docker-compose.prod-mysql.yml` 里 backend 的 `build:` 段替换为 `image: registry.cn-hangzhou.aliyuncs.com/命名空间/saidao-backend:v1`

## 附录 C：常见问题

| 问题 | 排查 |
|------|------|
| 打不开 IP:8080 | ① 安全组放行 8080？② 服务器 `curl http://localhost:8080`？③ `docker compose ps` 是否 healthy |
| backend 反复重启 | `logs --tail=100 backend`，多半是 MySQL 没就绪或 .env 没配 |
| MySQL 起不来 | `docker logs saidao-mysql`，检查 MYSQL_ROOT_PASSWORD 是否设置 |
| 域名解析后打不开 | 备案是否通过？A 记录是否生效（`ping 域名` 看 IP）？ |
| 上传大文件失败 | nginx `client_max_body_size` ≥ 50m |
| 想换阿里云 RDS | 改 `.env` 里的 DB_* 变量 + compose 里传入即可（模板见 `.env.example`） |
